# Moderator checklist (one per session)

Participant: **P__**  Stage: ______________  Device: ☐ laptop ☐ their phone  Date: ________

## 15 minutes before
- [ ] The site is awake: open it once (the free Render plan sleeps and takes about 1 minute to wake up)
- [ ] Logged **out**, starting on the **landing page**
- [ ] (If skipping sign-up) created their account: `php artisan pager:participant P_ --type=___`
- [ ] Screen + audio recording ready (only if consent given)
- [ ] Task cards, SUS form, and notes sheet ready; water for the participant

## Intro (3 min)
- [ ] Go through the **consent form**, get agreement, fill in the P-code
- [ ] Say: *"We're testing the app, not you. Please think out loud. I can't help during tasks, but I'll answer everything at the end."*
- [ ] Start recording

## Warm-up (3 min)
- [ ] "How do you keep track of your child's development or special moments today?"
- [ ] "Where do you go when you have a parenting question?"

## Tasks (20–25 min)
Read each card from [04-task-cards.md](04-task-cards.md). For every task, note **result**, **time**, **what they tried first**, and **one quote**.

| Task | Result (✓ / ~ / ✗) | Time | Notes |
|---|---|---|---|
| T1 What is this app for? | | | |
| T2 Create an account | | | |
| T3 Write about today | | | |
| T4 Find milestones | | | |
| T5 Find a useful tip | | | |
| T6 Talk to a professional | | | |
| T7 Update your situation | | | |
| T8 Delete your entry | | | |

✓ = did it alone · ~ = did it with difficulty or a hint · ✗ = gave up or needed help

## While they work, DON'T
- Don't help, point, or say "almost!" If they're stuck for 2 minutes, move to the next task.
- Don't use the words on the buttons in your questions.
- Don't defend the design. Just ask "What did you expect to happen?"

## Useful neutral prompts
- "What are you thinking right now?"
- "What did you expect to happen?"
- "Where would you look for that?"
- "You're doing great, this is exactly what we need." *(between tasks, not during)*

## Wrap-up (5 min)
- [ ] Most useful part? Most frustrating?
- [ ] "How likely are you to use this again next week, 1–5? Why?"
- [ ] "Would you feel comfortable writing private things here? Why?"
- [ ] "If you could change one thing, what would it be?"
- [ ] Hand them the **SUS questionnaire**
- [ ] Stop recording, give the thank-you gift, thank them

## Right after (10 min, while it's fresh)
- [ ] Copy notes into [06-results-template.csv](06-results-template.csv)
- [ ] Write the top 3 things you noticed
