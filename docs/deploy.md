# Deploying PAGER to Render

Everything in the repo is ready: `Dockerfile`, `docker/entrypoint.sh`, `.dockerignore`, and the `render.yaml` Blueprint (a web service + a free Postgres database). What's left needs **your** accounts, so it can't be done from the code.

## What happens automatically
On every deploy the container:
1. Listens on Render's `$PORT`.
2. Builds the Laravel config/route/view caches.
3. Runs database migrations.
4. Creates (or promotes) the admin from `ADMIN_EMAIL` / `ADMIN_PASSWORD`, if set.

`APP_KEY` is generated by Render. `APP_URL` defaults to your Render URL, which is used in email links.

## Step 1: Pick an email provider (about 10 minutes)
Verification and password-reset emails need a real SMTP server. Any of these work:

| Provider | Free tier | Where to find SMTP details |
|---|---|---|
| **Brevo** | 300 emails/day | Settings → SMTP & API |
| **Resend** | 3,000/month | Settings → SMTP |
| Gmail | Small volume | Needs 2-step verification + an "App password"; host `smtp.gmail.com` |

Write down: **host**, **username**, **password/API key**, and the **from address** you verified with the provider.

## Step 2: Create the Blueprint on Render (about 10 minutes)
1. Sign in at https://dashboard.render.com with your GitHub account.
2. **New +** → **Blueprint** → choose the `Zakuro28/Pager` repo → **Connect**.
3. Render reads `render.yaml` and asks for the secret values:

| Key | What to enter |
|---|---|
| `ADMIN_EMAIL` | Your email (becomes the first admin) |
| `ADMIN_PASSWORD` | A **strong** password, at least 8 characters, **not** `admin123` |
| `MAIL_HOST` | From Step 1 |
| `MAIL_USERNAME` | From Step 1 |
| `MAIL_PASSWORD` | From Step 1 |
| `MAIL_FROM_ADDRESS` | The sender address you verified in Step 1 |

4. Click **Apply**. The first build takes about 5–10 minutes.

## Step 3: Check it
1. Open the URL Render shows (for example, `https://pager-xxxx.onrender.com`).
2. Register a test account and confirm the verification email arrives.
3. Try **Forgot password?** on the login page.
4. Log in at `/admin/login` with `ADMIN_EMAIL` / `ADMIN_PASSWORD`.

After this, **every push to `main` redeploys automatically.**

## Good to know about Render's free tier
- The web service **sleeps after about 15 minutes idle**, so the first visit after that takes about a minute. Upgrade the plan before running usability sessions, or open the site a minute early.
- **Free Postgres databases expire** after a limited period. Check Render's current free-tier terms and upgrade the database before real users rely on it.
- Logs: Render dashboard → `pager` → **Logs**.

## Local development is unchanged
Locally you still use SQLite, `php artisan serve`, and emails written to `storage/logs/laravel.log`.
